## About Me

I'm a **Data Scientist** focused on transforming data into intelligent and practical solutions.

My interests are centered around **Machine Learning, Generative AI, predictive modeling, recommendation systems, time series and data-driven problem solving**.

I enjoy understanding the problem behind the data, experimenting with different approaches and turning models into solutions that can actually be used.

Currently, I'm expanding my knowledge in **GenAI, RAG architectures, MLOps, APIs, Docker and modern AI applications**.
